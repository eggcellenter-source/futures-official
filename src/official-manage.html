歷史資料與計算範圍

股期溢價以結算週期內的「期貨結算價 − 現貨收盤價」÷ 現貨收盤價，每日等權平均。大型、小型及 ETF 標準契約按官方乘數合計市值；調整型契約不混入排名。未額外還原除權息，因此除權息附近仍需留意比較基準。

融券增減使用前次結算日餘額作基準；未公告或缺少紀錄顯示「—」。選擇權到期日直接使用期交所欄位，包含休市調整。PCR 回測只計入同時有前一交易日 PCR 與當日 OHLC 的實際到期日；無樣本區間不顯示勝率。

法人方向分數為外資與投信的 (買 Call − 買 Put) + 0.5 × (賣 Put − 賣 Call)，以最多 120 個已保存交易日計算 z 分數；未滿 20 日顯示資料累積中。z≤−1.5／−0.5／0.5／1.5 為五個等級界線。

更新失敗時保留最近成功版本，最多重試三次；休市不寫入空資料。這是盤後資料，不是即時報價。

手動更新與補資料

網站擁有者可在 GitHub Actions 開啟「Official daily data and Pages」，按 Run workflow；date 留空更新最新資料，輸入 YYYY-MM-DD 可補指定交易日。訪客不能修改資料。

排程可能延遲；公開儲存庫連續 60 日沒有活動時，GitHub 可能停用排程。請由工作紀錄確認實際執行情況。資料來源失敗時保留上一版。
